# Crypto Visualizer — учебное приложение для демонстрации блочного шифрования

Настольное приложение на Python (PySide6) с единым GUI и меню выбора
алгоритма. Состоит из двух страниц:

1. **AES Visualizer** — наглядная, пошаговая демонстрация работы
   стандарта AES (FIPS-197), а также экспериментального (не-стандартного)
   блочного шифра с настраиваемыми параметрами.
2. **Сеть Фейстеля** — учебная реализация классической сети Фейстеля с
   пошаговым протоколом каждого раунда (L, R, K, F(R,K)) и наглядной
   схемой раунда.

Обе страницы работают полностью независимо друг от друга и не сбрасывают
данные друг друга при переключении.

## 1. Установка

```bash
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Зависимость всего одна — `PySide6` (GUI-фреймворк на базе Qt6).

## 2. Запуск

```bash
python main.py
```

## 3. Запуск тестов

```bash
python -m unittest app.tests.test_aes -v
```

Тесты включают официальные тестовые векторы NIST FIPS-197 для AES-128/192/256,
проверки обратимости каждого преобразования (SubBytes/ShiftRows/MixColumns),
проверки Key Expansion, корректность работы с русским/китайским/японским/
арабским Unicode-текстом, а также проверку критического случая — данные,
которые сами оканчиваются нулевыми байтами, и padding не должен их
"откусить".

## 5. Алгоритм: коротко

### AES Standard (режим "AES")

Строго по FIPS-197:

| Параметр            | AES-128 | AES-192 | AES-256 |
|---------------------|---------|---------|---------|
| Размер блока        | 128 бит (фиксировано) | 128 бит | 128 бит |
| Размер ключа        | 128 бит | 192 бит | 256 бит |
| Число раундов       | 10      | 12      | 14      |

Каждый раунд (кроме последнего): SubBytes → ShiftRows → MixColumns → AddRoundKey.
Последний раунд: SubBytes → ShiftRows → AddRoundKey (**без** MixColumns).

Дешифрование выполняет обратные операции в обратном порядке: InvShiftRows,
InvSubBytes, InvMixColumns, с раундовыми ключами в обратном порядке.

### Experimental AES-like Cipher (режим "Учебный")

Тот же общий принцип SPN (Substitution-Permutation Network), но со
свободно настраиваемыми:
- размером блока (64/128/192/256 бит),
- размером ключа (64/128/192/256 бит — **64 бита не является стандартным
  ключом AES**),
- числом раундов (10/12/14/16),
- S-box (сгенерированной пользователем на вкладке "S-box"),
- линейным преобразованием (AES-подобное ShiftRows+MixColumns, XOR
  соседних байт, циклический сдвиг, перестановка битов).

Приложение явно и постоянно показывает, что это **не является стандартом
AES** (метка "Experimental AES-like Cipher", предупреждающие сообщения).

## 6. S-box

По умолчанию используется официальная S-box AES. На вкладке "S-box" можно
сгенерировать новую таблицу: приложение пытается получить дополнительную
случайность со страницы `http://www.waysidehealth.com/Projects/crypto/Sbox.html`,
а если сайт недоступен — использует надёжный локальный резервный
генератор (инверсия в GF(2^8) + аффинное GF(2)-преобразование со
случайной константой — та же математическая идея, что лежит в основе
самой стандартной S-box AES, но с иным случайным параметром при каждом
нажатии кнопки). В обоих случаях итоговая таблица гарантированно
биективна (обратима), поэтому inverse S-box для дешифрования вычисляется
автоматически.

## 7. Формат контейнера шифротекста

Чтобы можно было расшифровать данные даже после перезапуска приложения,
результат шифрования сохраняется как JSON-объект (версия формата, режим,
размер блока/ключа, число раундов, используемая S-box и её метаданные,
линейное преобразование, IV при CBC, исходная длина данных, сам
шифротекст в HEX), закодированный в Base64 для удобства копирования одной
строкой.

## 8. Примеры

- **Русский текст**: «Привет, мир!» шифруется как обычные UTF-8 байты —
  никаких ограничений на алфавит.
- **Китайский/японский**: «你好世界» / «こんにちは世界» — тоже корректно
  кодируются в UTF-8 (несколько байт на иероглиф) и шифруются блоками.
- **Дешифрование ранее сохранённого шифротекста**: вставьте контейнер
  (Base64-строку) на вкладку "Дешифрование" и нажмите "Расшифровать" —
  приложение восстановит все параметры автоматически.

## 6. GUI через JSON-конфигурацию

Заголовок и размер окна, подписи меню, названия вкладок верхнего уровня и
все тексты полей/кнопок вкладки "Сеть Фейстеля" вынесены в
`config/ui.json` и загружаются модулем `app/gui/config_loader.py`. Если
файл отсутствует или повреждён, приложение не падает — используются
встроенные значения по умолчанию, идентичные исходному JSON.

## 7. Сеть Фейстеля

Модуль `app/crypto/feistel.py` реализует алгоритм "вручную" — без
использования готовых крипто-библиотек, чтобы вся логика была видна:

- `generate_round_keys(key, num_rounds, half_block_bytes)` — раундовые
  ключи через SHA-256(key ‖ номер_раунда);
- `F(right, round_key)` — XOR с ключом → замена через S-box AES (для
  нелинейности) → циклический сдвиг на 1 байт;
- `feistel_round()` / `feistel_inverse_round()` — один прямой/обратный
  раунд по классической схеме `L_i = R_{i-1}`, `R_i = L_{i-1} ⊕ F(R_{i-1}, K_i)`;
- `feistel_encrypt()` / `feistel_decrypt()` — обработка многоблочных
  сообщений (аналогично режиму ECB в AES-части).

На вкладке "Сеть Фейстеля" можно менять текст, ключ, число раундов (1–16)
и размер блока (4/8/16/32 байта), видеть полный текстовый протокол
каждого раунда и кликабельную схему `L → F → XOR → R`, обновляющуюся при
выборе раунда.

## 8. Меню приложения

- **Методы шифрования** → *AES Visualizer* / *Сеть Фейстеля* — переключение
  между вкладками верхнего уровня.
- **Настройки** → *Тема оформления...* — переходит на вкладку AES → "Настройки",
  где переключается общая (единая для всего приложения, включая схему
  Фейстеля) светлая/тёмная тема.
- **Справка** → *О программе* — переходит на вкладку AES → "О программе"
  (словарь терминов, самопроверка AES).

## 9. Важное предупреждение

Это приложение создано **исключительно в учебных целях** — для наглядной
демонстрации внутреннего устройства AES. Экспериментальный режим
специально ослаблен и изменяем и **не должен использоваться для защиты
реальных данных**. Для реальной защиты данных используйте проверенные
криптографические библиотеки (например, `cryptography` в Python) с
режимами, обеспечивающими аутентификацию (например, AES-GCM), а не режим
ECB/CBC без MAC, используемый здесь в учебных целях.

## 10. Обновлённый учебный режим Feistel

Вкладка **«Сеть Фейстеля»** теперь работает с двоичным вводом и содержит три
подвкладки: **«Основное»**, **«S-box»**, **«Диаграмма»**. Для каждого раунда
исполняется строго следующая функция:

```text
F(R, K) = RotateRight(S-box(R XOR K), 1 бит)
L(i+1) = R(i)
R(i+1) = L(i) XOR F(R(i), K(i))
```

Padding выполняется только нулями с двух сторон. Для каждого существенного
значения GUI показывает Binary и HEX. Таблица раундов и диаграмма используют
фактические результаты вычислений. Цвета фиксированы: жёлтый — L, синий — R,
красный — F(R,K). Диаграмма имеет 6 пошаговых состояний.

`app/crypto/sbox.py` строит S-box полностью локально и алгоритмически через
арифметику GF(2^8), мультипликативную инверсию и аффинное преобразование.
HTTP-запросов, WebView, iframe и браузера для S-box нет.

Раундовые ключи нового битового учебного GUI получаются прозрачным учебным
расписанием: исходный дополненный ключ циклически сдвигается влево на номер
раунда. Старый байтовый API Feistel оставлен как слой совместимости, чтобы не
ломать существующие тесты и интеграции проекта.
